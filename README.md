# BellaTen — Loja + Painel Administrativo

Projeto React + Vite responsivo, baseado no layout aprovado.

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite.

## Rotas

- `/` — loja responsiva
- `/admin` — painel administrativo

## O que já funciona

- Layout web e mobile
- Busca e filtro por categoria
- Carrinho com quantidades
- Cadastro, edição e exclusão de produtos
- Controle de estoque
- Persistência local usando `localStorage`
